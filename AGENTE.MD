# Contexto del Proyecto

## Stack Tecnológico
- **Frontend:** React 19 con TypeScript y Tailwind CSS.
- **Backend:** Node.js con Express y PostgreSQL.
- **Gestor de paquetes:** pnpm.

## Comandos Útiles
- Iniciar entorno de desarrollo: `pnpm dev`
- Ejecutar pruebas: `pnpm test`
- Compilar para producción: `pnpm build`

## Reglas y Decisiones de Estilo
- Usar funciones flecha y componentes funcionales limpios.
- Escribir siempre los comentarios y la documentación en español.
- No instalar librerías nuevas sin consultar previamente.
- Seguir una estructura de arquitectura modular por carpetas.
